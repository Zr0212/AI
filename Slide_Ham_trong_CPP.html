Phân biệt return và cout

Đây là một trong những nhầm lẫn phổ biến nhất.

return · Trả kết quả

Kết quả dùng tiếp
int binhPhuong(int x) {
    return x * x;
}
int kq = binhPhuong(5);

Giá trị 25 được đưa về biến kq, có thể dùng trong phép tính khác.

cout · Hiển thị

Kết quả chỉ được in
void inBinhPhuong(int x) {
    cout << x * x;

inBinhPhuong(5);

Mẹo: Hàm tính toán thường nên trả kết quả bằng return, sau đó main() in bằng cout.

Truyền tham trị và tham chiếu

Cùng một giá trị đầu vào nhưng cách truyền quyết định việc biến gốc có đổi không.

Tham trị · Bản sao

Pass by value
void tang(int x) {
    x++;
}
int a = 5;
tang(a);  // a van = 5

Thay đổi x không làm đổi biến a.

Tham chiếu · Biến gốc

Pass by reference
void tang(int &x) {
    x++;
}
int a = 5;
tang(a);  // a = 6

Dấu & cho phép sửa trực tiếp biến a.

Mẹo chuyên sâu: const vector<int>& a truyền mảng lớn mà không phải sao chép và không cho phép sửa.

Hàm đệ quy là gì?

Ví dụ quen thuộc: n! = n × (n − 1)!, với 0! = 1.

Điều kiện: 0 <= n <= 20
long long giaiThua(int n) {
    if (n <= 1) return 1;
    return n * giaiThua(n - 1);
}
Đệ quy là hàm tự gọi lại chính nó với bài toán nhỏ hơn.
giaiThua(4)
4 × giaiThua(3)
4 × 3 × giaiThua(2)
4 × 3 × 2 × giaiThua(1)
4 × 3 × 2 × 1 = 24
Bắt buộc: Cần điều kiện dừng, nếu không lời gọi đệ quy có thể tiếp tục đến khi tràn ngăn xếp.
